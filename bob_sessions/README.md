Exported IBM Bob task histories and the consumption-summary screenshot for each task, as the hackathon requires.

| Task | What Bob did | Files |
|---|---|---|
| [date] Translate and certify `interest.cbl` | Translated COBOL to Java, ran Parity through MCP, repaired 5 findings, produced the certificate | `[task-1].md`, `[task-1-summary].png` |

How these were exported: Bob chat → Views and More Actions → History → select the task → click the task header → screenshot the summary → Export task history.

Filenames avoid the words token, secret, password and credential, because the repository's `.gitignore` would silently skip them.
